HyForm™

HyForm, on your device.

This standalone adaptation runs the original HyForm drone designer, local flight evaluator, operations planner, and business planner in your browser. Project data is stored locally and can be downloaded as a versioned JSON file. It does not include team collaboration, server AI, or experiment administration.

Browser storage can be cleared by your browser. Download project files to keep durable copies. Flight, operations, and business results use the original HyForm research models and their assumptions.

Source and attribution

Original work: Copyright 2020 Carnegie Mellon University / The Pennsylvania State University / Applied Research Laboratory. Original repositories: Unity interface and server and WebGL build. This adaptation adds a static browser shell, device-local storage, and project-file import/export. The Unity build is retained unmodified.
